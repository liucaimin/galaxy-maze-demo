# 图片资源说明

本目录只存放游戏使用的位图素材，便于后续替换真实天文图像。

## levels/

- `level-01-spiral.png`：第 1 关目标图，当前为仿真旋涡星系。
- `level-02-elliptical.png`：第 2 关目标图，当前为仿真椭圆星系。

目前 36 关会按类别复用已有的关卡底图和 `examples/` 中的形态图。后续补充真实图片时，可以在本目录继续按关卡编号命名至第 36 关。建议使用正方形图片，并确保星系主体位于中央。

## examples/

- `example-smooth.png`：光滑/椭圆形态标准参照。
- `example-edge-on.png`：侧视盘与尘埃带标准参照。
- `example-barred.png`：中心棒结构标准参照。
- `example-spiral-arms.png`：旋臂标准参照。

这些图片会同时出现在问题弹窗和分类指南中。后续可以继续添加环、并合、引力透镜等专用范例。

## puzzle/

- `puzzle-galaxy.jpg`：左下角通关拼图的完整底图，页面会自动切分为 6 × 6、共 36 块带半圆边缘的拼图。

## guide/

- `galaxy-decision-tree.svg`：操作指南中展示的完整分类决策树，按用户提供的流程图重绘，游戏问题和跳转逻辑与其保持一致。

当前全部图片均为 AI 生成的仿真图，不代表真实巡天观测数据。
